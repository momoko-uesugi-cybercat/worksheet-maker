      1. Make prompt: enter the details, load the final script (Google Docs → File → Download → Markdown) or paste it, click Copy prompt.
        2. 
        
      2. Open a new chat in Claude. If the script has figures, attach the script PDF (Google Docs → File → Download → PDF). Paste the prompt and send. Claude replies with the worksheet as JSON.
        3. 
        
      3. Preview: paste the reply in step 2. Fix any red errors (ask Claude to fix them).
        4. 
        
      4. Check every question and answer yourself: is the maths right, does it match the video, is the Bangla clear?
        5. 
        
      5. Revise: use step 3 in the same chat until you are happy.
        6. 
        
      6. Save the JSON and a PDF (with answer key) and submit for BUET review.
        7. 
        
      7. After BUET review: paste their feedback in step 3, get the final version, save JSON + PDF again.
